Tools for people who make VJ loops and digital visuals.

Everything runs inside your browser. Your files never leave your computer.

1. Files

Drop videos here or

Big files are fine: they are read straight from your disk. The browser version is slower than the desktop version (about 5-10 times), so for lots of large 4K files use the Linux/command-line version.

2. Pick looks

Click the looks you want. Every file gets one new clip per look. Press Preview to see each look on the first selected clip.

2. Pick sizes

Every file gets one new clip per size. A size bigger than the clip itself is skipped. Use the small proxy for editing on a slow computer, and the big ones for the show.
