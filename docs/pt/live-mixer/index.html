Video DJ

Misture videoclipes completos como um DJ. Feito para ser sólido em eventos, com uma saída preparada para um projetor HDMI.

Abrir o mixerVersão para celular📖 Guia

O mixer completo é feito para um computador com Chrome ou Edge. Em um celular você é enviado a uma versão mais simples com dois decks, crossfader, efeitos, cartazes, tela cheia e uma forma de enviar a imagem para outra tela. Ele é novo: teste em casa antes de um show e tenha um plano B.

O que ele faz

  • Dois decks para videoclipes (mp4, mov, webm). Som e imagem são mixados juntos.
  • Crossfader manual ou um botão para uma fusão automática. A mixagem automática até deixa a próxima faixa pronta para você.
  • Prévia dos dois decks ao lado da saída.
  • Seu próprio logotipo no canto superior direito.
  • Cartazes de texto deslizantes em cores predefinidas, salvos em posições. Eles podem mostrar o nome da faixa sozinhos.
  • Controle MIDI com aprendizado.
  • Uma janela de saída limpa para o projetor e um gravador.
  • Uma verificação “Pronto para o show?” que confere seu computador, navegador e tela antes de entrar.

Feito para não travar

As faixas são carregadas inteiras na memória antes de tocar. Um problema com um arquivo mostra uma mensagem e nunca para o outro deck. A imagem continua rodando mesmo com a janela de controle em segundo plano, e fechar a janela por engano pergunta antes.

Streaming e transmissão

Capture a janela de saída no OBS (Window Capture) para fazer streaming, ou use a opção Transmitir do Chrome e escolha a janela de saída. O mixer em si não envia vídeo pela internet.
