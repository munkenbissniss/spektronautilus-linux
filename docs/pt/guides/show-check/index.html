✅ Pronto para o show? Verifique o seu dispositivo antes de ir ao vivo

Uma verificação de um minuto do seu computador e navegador antes de um evento: formato de vídeo, segundo ecrã, som, bateria, velocidade e mais.

O que é

Dentro do Video DJ, do Mixer VJ e das suas versões para telemóvel encontra Pronto para o show?. Verifica o seu dispositivo e o navegador em um minuto e diz-lhe o que corrigir antes de o público chegar. Nada é enviado para lado nenhum.

Como usar

  1. Abra o mixer no computador que vai usar no evento, com o projetor ligado.
  2. Abra Pronto para o show? e leia a lista. Cada linha é OK, Verificar, Problema ou Info.
  3. Corrija o que for preciso e carregue em Refazer a verificação.
  4. Carregue em Mostrar imagem de teste para ver se a imagem cabe no projetor.

O que significa cada linha

  • Formato de vídeo. Se o navegador reproduz mp4 (H.264), de que os mixers mais gostam. Se não, use Chrome, Edge ou Safari, ou converta os seus vídeos com as Ferramentas.
  • Funciona sem internet. Se o site está guardado para uso sem ligação. Veja Sem internet e Linux.
  • A tela fica ligada. Se o navegador consegue impedir que o ecrã adormeça. Se não, desligue a proteção de ecrã e a suspensão nas definições do sistema.
  • Janelas pop-up. A janela de saída é uma janela pop-up. Se o navegador bloqueia pop-ups, a janela de saída não consegue abrir.
  • Segunda tela. Se é encontrado um segundo ecrã. Ligue primeiro o projetor.
  • Tela cheia e Controlador MIDI. Se estão disponíveis e se há um controlador ligado.
  • Som. Se o som está pronto.
  • Bateria. Avisa se a bateria está baixa. Ligue à corrente antes do show.
  • Velocidade. Um teste curto de quantos fotogramas por segundo o ecrã consegue desenhar. Se for lento, feche outros separadores e programas e use um tamanho de imagem menor.
  • Espaço livre. Avisa quando há pouco espaço em disco para gravar.
  • Janela de saída, loops e faixas. Se a janela de saída está aberta e se algo está carregado.

A imagem de teste

Mostrar imagem de teste abre uma imagem feita para projetores. Se vir um círculo redondo, os quatro cantos e a moldura cor-de-rosa, a imagem cabe no ecrã. Carregue em F para ecrã inteiro e em Esc ou clique para fechar.

Pedir ajuda com um relatório

Copiar relatório copia um breve resumo do seu dispositivo em texto simples. Cole-o numa mensagem quando pedir ajuda com o botão Comentários, veja Ajuda.
