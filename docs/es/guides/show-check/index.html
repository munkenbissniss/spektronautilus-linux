✅ ¿Listo para el show? Comprueba tu dispositivo antes de salir en vivo

Una comprobación de un minuto de tu ordenador y tu navegador antes de un evento: formato de video, segunda pantalla, sonido, batería, rendimiento y más.

Qué es

Dentro de Video DJ, el Mezclador VJ y sus versiones para móvil encuentras ¿Listo para el show?. Comprueba tu dispositivo y tu navegador en un minuto y te dice qué arreglar antes de que llegue el público. No se envía nada a ningún sitio.

Cómo usarla

  1. Abre el mezclador en el ordenador que usarás en el evento, con el proyector conectado.
  2. Abre ¿Listo para el show? y lee la lista. Cada línea es OK, Revisar, Problema o Info.
  3. Arregla lo que haga falta y pulsa Repetir la comprobación.
  4. Pulsa Mostrar carta de ajuste para ver que la imagen encaja en el proyector.

Qué significa cada línea

  • Formato de video. Si el navegador reproduce mp4 (H.264), que es lo que mejor les va a los mezcladores. Si no, usa Chrome, Edge o Safari, o convierte tus videos con las Herramientas.
  • Funciona sin internet. Si la web está guardada para usarla sin conexión. Mira Sin internet y Linux.
  • La pantalla se mantiene encendida. Si el navegador puede evitar que la pantalla se apague. Si no, desactiva el salvapantallas y la suspensión en los ajustes del sistema.
  • Ventanas emergentes. La ventana de salida es una ventana emergente. Si el navegador las bloquea, la ventana de salida no se puede abrir.
  • Segunda pantalla. Si se encuentra una segunda pantalla. Conecta primero el proyector.
  • Pantalla completa y Controlador MIDI. Si están disponibles y si hay un controlador conectado.
  • Sonido. Si el sonido está listo.
  • Batería. Avisa si la batería está baja. Enchúfalo antes del show.
  • Rendimiento. Una prueba corta de cuántos fotogramas por segundo puede dibujar la pantalla. Si es lenta, cierra otras pestañas y programas y usa un tamaño de imagen menor.
  • Espacio libre. Avisa cuando hay poco espacio en disco para grabar.
  • Ventana de salida, loops y pistas. Si la ventana de salida está abierta y si hay algo cargado.

La carta de ajuste

Mostrar carta de ajuste abre una imagen hecha para proyectores. Si ves un círculo redondo, las cuatro esquinas y el marco rosa, la imagen encaja en la pantalla. Pulsa F para pantalla completa y Esc o haz clic para cerrarla.

Pedir ayuda con un informe

Copiar informe copia un breve resumen de tu dispositivo en texto plano. Pégalo en un mensaje cuando pidas ayuda con el botón Comentarios, mira Ayuda.
